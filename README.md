# LowFracRate

LowFracRate is set of MATLAB-based codes designed for the processing the raw data from four hydraulic fracturing experiments: M03, M04, M05, and M08. Each experiment has its own conditions. 

To use the code, simply place the main MATLAB code and its corresponding subcode in the same directory as the data.

For each experiment, run the respective file: 

Low_Rate_Data_Process_Code_11_02_M03.m,
Low_Rate_Data_Process_Code_12_12_M04.m,
Low_Rate_Data_Process_Code_12_06_M05.m,
Low_Rate_Data_Process_Code_01_18_M08.m

Beside their own subcodes folder of

M03_subcodes,
M04_subcodes,
M05_subcodes,
M08_subcodes

In M03 and M05, we injected glucose using an interface vessel and ISCO pump, while in M04 and M08, glycerol was injected directly from the Top Industrial pump.

Everything is pre-tuned, so no additional adjustments are needed. Just ensure you add the respective subcode directory (e.g., M03_subcodes) to MATLAB before running the main file for each experiment.
